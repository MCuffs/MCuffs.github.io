# Rehearsal: AgentImpact (`.pa`)

- 바탕 골드: `table-edit`(창 하나를 위·좌우 여백에 두고 아래로 자름, 원인 뒤에 값이 굴러 바뀜). 큰 값과 작은 추세선은 `chart-scrub`에서 빌림. 골드 자체는 촬영하지 않고 소스만 읽고 옮김.
- 바꾼 것: 옆 메뉴가 있는 분석 창(900×480)으로 다시 짬. 비트는 지표 전환(결제 전환 → 7일 리텐션, 6.8%·4.1% → 41%·33%) → 「이탈 직전 대화」 탭 → 유형 막대 여섯 줄이 차례로 자람 → 「환불 문의」 한 줄 강조와 배지. 평소 분포는 막대 뒤 눈금으로 표시. 정지 화면은 강조가 끝난 상태.
- 좁은 화면(358×342): 옆 메뉴와 설명 줄을 빼고 창을 가까이 자름. 높이는 요청의 약 400 대신 342 — 404에서는 게이트가 `framing`(보이는 창이 세로로 김)으로 실패해 정사각으로 맞춤. 창 제목 줄의 필터 아이콘 버튼은 `uneven inset` 해소용(히어로와 같은 처리).
- 게이트: 1280 `rehearsal passed`, 390 `rehearsal passed`. 남은 줄은 두 폭 모두 `manual: same-box content change: ss-chart`(추세선이 지표 전환 때 모양을 바꾸는 것, 의도) 2건과 샘플링 간격으로 인한 `inconclusive`뿐. `npx tsc --noEmit` 통과.
- 확인하지 않은 것: 실제 브라우저에서 실시간 재생(헤드리스 촬영 시트와 정지 화면만 봄), 다크 모드, Safari·실기기, 재생 도중 「다시 보기」·화면 밖 복귀, `--states`·새 눈 검토(review.md). 무대는 900 폭이라 960 칸에서는 60px이 남음.
