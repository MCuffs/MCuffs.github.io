# Rehearsal · KakaoSend (`.pk`)

- 바탕 골드: `device-pair` (창은 위·왼쪽 여백에 고정되어 아래로 잘리고, 휴대폰이 창의 오른쪽 가장자리에 걸침). 숫자가 굴러 올라가는 방식은 `subscriptions`의 `Count`를 따름.
- 바꾼 것: 900×480, 사이드바 창 + 왼쪽 열(작업 이름 · 「발송」 버튼 · 발송/도달/클릭 퍼널 세 줄) + 막대 목록. 클릭 → 버튼이 같은 자리에서 「발송 완료」 → 발송 수 → 잠금 화면 알림(`Collapse reveal="drop"`) → 도달 → 클릭. 잠금 화면 배경은 파랑 계열만, 알림 앱 이름은 「쇼핑몰」, 아이콘은 lucide 쇼핑백. 비어 있을 때의 0도 `Count`로 그려 끝자리가 같은 자리에서 이어짐.
- 좁은 화면(358×410): 사이드바·목록을 빼고 퍼널을 세 칸으로 다시 짬. 창은 오른쪽으로만 잘리고(가로로 긴 모양 유지), 휴대폰은 퍼널 아래에서 창의 아래 가장자리에 걸쳐 무대 밑으로 나감. 알림 본문이 10px 이상으로 읽히도록 휴대폰 폭 288을 그대로 둠(높이가 요청한 약 400보다 10 큼).
- 게이트: 1280 `rehearsal passed`, 390 `rehearsal passed`. `npx tsc --noEmit` 통과.
- 남은 경고: 촬영 간격이 벌어진 회차에서만 `appears with no entrance: span.ss-count.pk-step__value`가 한 줄 나옴(5회 중 2회). 70ms 간격 확대 촬영으로 0.5초 페이드가 있는 것을 확인함. 모든 회차가 `inconclusive`(다른 촬영과 겹쳐 27ms 넘는 간격 40~75개)로 끝남.
- 확인 안 한 것: 다크 모드, Safari·실기기, 실제 속도로 본 재생(연속 사진으로만 확인), 재생 중 「다시 보기」·탭 전환·화면 폭 변경, `--states`, 별도 사람의 fresh-eye 검토.
