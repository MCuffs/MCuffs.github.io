# Rehearsal: CrmApproval (`.pc`, /planning/#ai-crm)

- 바탕 골드: `ai-cards`(카드가 대화 안에서 열리고 카드 자신의 버튼으로 확정). 값이 막대에서 글자로 바뀌는 방식은 `loading`에서 가져옴.
- 바꾼 것: 900×480 사이드바 창(메뉴 4줄·지난 대화 8줄은 막대), 요청 입력·전송 → 초안 카드(대상·메시지·발송이 위에서부터 채워짐) → 승인 버튼이 회색에서 강조색으로 → 클릭 → 같은 `Button`이 「발송 예약됨」(완료색, 체크 아이콘). 좁은 화면은 사이드바 없는 대화 창으로 다시 짬.
- 좁은 화면 높이는 요청의 약 400이 아니라 342: 400이면 보이는 창이 326×384로 세로가 길어 게이트의 `framing`에 걸림(히어로 `AgentAnswer`와 같은 342).
- 게이트 1280: `rehearsal passed`. 390: `rehearsal passed`. 남은 줄은 두 폭 모두 입력 중 글자 폭이 늘어나는 `jump`(골드와 히어로에도 있음)와 촬영 간격 때문에 붙는 `inconclusive` 표시뿐.
- 확인한 것: 두 폭의 대조 시트 전 구간, 모션 줄이기 설정의 정지 화면(1280), `npx tsc --noEmit`.
- 확인하지 않은 것: 다른 눈의 검토(review.md), `--states` 시트, 390의 모션 줄이기 화면, 다크 모드, 실제 브라우저에서 실시간 재생·「다시 보기」·창 폭을 바꿀 때의 전환, Safari와 실기기.
