# mcuffs.github.io

정민수(Minsu Jung) 포트폴리오. https://mcuffs.github.io

- Vite + React. 프로젝트 일러스트는 [stageshow](https://github.com/benjitaylor/skills) 키트(`src/kit`, MIT)로 만든 설명용 화면입니다.
- `main`에 푸시하면 GitHub Actions가 빌드해 Pages에 올립니다.
- 로컬: `npm install` → `npm run dev` (http://localhost:5190)
- 일러스트 점검: `npm run film -- "http://localhost:5190/" --select ".aa" --gate --width 1280`

2022년의 이전 페이지(머신러닝 실습 템플릿)는 git 기록에 남아 있습니다.
